# 5 分钟演示

1. **启动（30 秒）**：运行 `start.cmd`，访问本机 8000 端口，点击启动演示。出现四个 demo 节点，自动生成一分钟模拟历史，再每秒采样。说明数据是合成的。
2. **故障闭环（60 秒）**：注入过热，连续三点超过 75 °C 后开启告警。确认后待恢复仍为 1；正常场景连续三点低于 70 °C 后归零。说明防抖、迟滞和人工确认的区别。
3. **断联与补传（60 秒）**：网页模拟断联，5 秒后设备离线；恢复正常后上线。内置模拟器验证离线检测，不具有 outbox。另启 `edgepulse agent --offline-seconds 10`，演示真正经过磁盘队列和 HTTP 的补传。关闭再重开服务端可以进一步观察退避重试。
4. **历史复盘（45 秒）**：回放选择 demo-pump-01，播放、暂停、拖动到故障前后，导出 CSV 逐点核对。回放读取已存样本，不再次触发告警。
5. **工程证据（45 秒）**：运行测试，解释冲突回滚和在途写入停止测试；打开基准 JSON，说明只是本地存储速度。最后说明实物、身份认证和大规模存储仍待验证。
