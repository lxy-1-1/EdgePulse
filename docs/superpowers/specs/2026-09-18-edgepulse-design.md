# EdgePulse 设计

面向设备遥测的单机工程项目。无需真实硬件，使用明确标注的模拟数据完成故障注入、可靠上报、告警与历史回放闭环；真实设备可通过 HTTP JSON 协议接入。

## 范围和架构

Python 3.10+ / FastAPI / SQLite WAL / 原生 HTML、CSS、JavaScript。独立目录和独立 Git 仓库，作者仅为 lxy-1-1，上传到新建私有仓库 EdgePulse。

设备代理 -> 本地 SQLite outbox -> 批量 HTTP 上报 -> 服务端事务去重 -> 顺序检查 -> 告警状态机 -> SQLite -> WebSocket 仪表盘。默认绑定 127.0.0.1。外部 API 可通过环境变量配置 Bearer token。仪表盘与 API 同源。无云服务、无付费 API、无硬件依赖。

## 数据契约

每条样本具有 device_id、boot_id、seq、ts 和 temperature/vibration/current。以 (device_id, boot_id, seq) 去重；同 key 不同内容返回 409，并回滚整个批次。最多每批 500 条。NaN、Infinity、负序号和过远的未来时间拒绝。事件时间以毫秒保存。迟到数据入历史但不倒退当前状态。序号缺口是观测量，不承诺检测所有丢包。

## 告警和可靠性

温度高于 75°C、振动高于 4.5 mm/s、电流高于 12 A 连续 3 点开启告警；连续 3 点低于各自恢复阈值（70/3.5/10）恢复，防抖与迟滞状态跨服务重启保留。ACK 与 recovered 是不同状态；确认操作有审计记录，不等同于故障恢复。EWMA 跟踪温度趋势用于展示，不宣称经过工业数据验证的 AI 诊断。

代理先写磁盘再发送，只有服务端明确确认该批所有数据后删除队列。HTTP 超时、服务端错误和非完整确认均保留数据，下次重试。重新发送通过服务端去重安全落库。进程重启后队列保留。服务端一次事务写入样本、实时状态、告警与计数，避免部分提交。

## 演示和界面

四个模拟节点，一秒一次；温度升高、振动升高、设备断联、恢复正常可选。启动演示才产生模拟数据；独立代理额外展示真实 HTTP 上报及离线缓存。深色监控面板显示设备、最新指标、趋势、告警、接收计数。历史回放按设备和时间读取真实已存记录，支持播放、暂停、拖动进度。CSV 导出和 API 文档。

## 验收

覆盖幂等、冲突回滚、迟到数据、重启状态、阈值抖动、告警确认、非法数据、认证、API 集成、outbox 跨重启与重试。浏览器验证仪表盘故障注入及回放。提供可重复执行的本机性能基准及环境说明，禁止将本地入库速度宣传成网络吞吐。README 提供一键启动、架构、协议、限制和演示说明。

## 边界

单实例应用；SQLite 单写者，适合学习、边缘网关、小规模原型。尚无实物接入验证、工业级故障诊断、多租户、TLS 终端、数据保留策略或高可用承诺。演示模式不是安全控制系统。
