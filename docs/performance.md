# 本地性能测量

[原始结果](benchmark-results.json)。环境：Windows，Python 3.10.11，SQLite 3.40.1，16 逻辑处理器。

每轮新建磁盘数据库，10 个设备，10,000 条样本，每批 100 条，单写者，三轮无预热。模型预先构造，计时包含连接、SQLite 写入、状态机、统计与提交；WAL、FULL 默认同步。不包含 HTTP、网络、载荷解析或实物采样。

每轮写完后全部重传，断言去重 10,000 条、唯一样本仍为 10,000。重传不计入首次入库吞吐。数据为正常指标，不代表告警密集场景。

| 轮次 | 总耗时 | 样本/秒 | 每批 p50 | 每批 p95 | 每批 p99 |
|---|---:|---:|---:|---:|---:|
| 1 | 0.8914 s | 11,218 | 8.854 ms | 10.492 ms | 11.279 ms |
| 2 | 0.8938 s | 11,188 | 8.953 ms | 10.531 ms | 11.492 ms |
| 3 | 0.8777 s | 11,393 | 8.748 ms | 9.912 ms | 11.456 ms |

分位数按每轮 100 次批提交排序取索引，样本量较小。磁盘、杀毒软件、后台负载、批大小和依赖版本会影响结果，不应据此承诺线上容量。

```bash
python scripts/benchmark.py --samples 10000 --batch-size 100 --repeat 3 --output work/benchmark.json
```

正式容量评估还需要真实网络、并发设备、持续读写、告警密度、数据库增长和磁盘异常测试，本次没有覆盖。
